##  Project Structure & Topics Covered

Here is the structured breakdown of the foundational concepts implemented so far:

###  1. Logic Building & Mathematics
* **`Basic_maths_for_DSA.java`** 
  * Optimizing prime number checking from $O(n)$ to $O(\sqrt{n})$ using the `i * i <= n` condition.
  * Extensively debugging code for edge cases like checking digits, string reversals, and handling `ArithmeticException: / by zero`.
  * Palindrome numbers, GCD, and LCM calculation algorithms.

###  2. Nested Loops & Patterns
* **`Pattern_Printing.java` & `Pattern_printing_IInd.java`**
  * Advanced nested loop controls to build spatial awareness and geometric observation.
  * Printing complex block, star, and character matrix designs.

###  3. Core Syntax & Reusability
* **`First.java` & `Loops.java`**
  * Java anatomy: Understanding why all code resides inside a `public class`.
  * Loop structures (`for`, `while`) and flow control.
* **`Method_Programs.java`**
  * Exploring functions, parameter passing, stack behavior, and `static` vs `void` return structures.

###  4. Linear Data Structures & Strings
* **`Arrays.java`** - Memory layout, static allocation, array traversals, and multi-element logic.
* **`basic_string.java`** - Immutable nature of strings in Java, textual operations, and indexing methods.

##  Local Setup & Execution

If you want to explore or run these foundational programs on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Bhavesh-Sharma21/Basics_of_JAVA.git
   ```
2. **Navigate to the workspace folder:**
   ```bash
   cd Basics_of_JAVA
   ```
3. **Compile and execute any specific logic file (e.g., `Arrays.java`):**
   ```bash
   javac Arrays.java
   java Arrays
   ```

*(Note: A `.gitignore` has been properly configured to block unwanted `.class` build artifacts from cluttering the version control.)*
